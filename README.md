# Radar Semanal 4ComM · versão compartilhável

Repositório público de propósito único: serve pelo GitHub Pages um menu de semanas (`index.html`) e uma pasta por semana (`19out-25out/`, `26out-2nov/`, ...), cada uma com o resumo semanal da carteira que a 4ComM compartilha com terceiros.

**Exceção à regra de repositório privado (C16, 25/10/2026):** este repositório é público de propósito, por decisão do Felipe Mazmanian em 26/10/2026, porque o GitHub Pages precisa dele. Só entra aqui a versão sem dado interno (sem saúde, contrato, mercado, redes, contatos, gestor, artes, pendências ou dado de menor). A versão completa fica local, no Drive da 4ComM.

Atualização: semana nova = pasta nova com `index.html` e uma linha nova no menu; correção na mesma semana = sobrescrever o `index.html` da pasta (versão única), gerado por `relatorio_publico.py` em `GitHub\4comm-radar`.
